# Bundled Skills Catalog

Vetri ships with a large built-in skill library copied into `~/.vetri/skills/` on install. Each skill below links to a dedicated page with its full definition, setup, and usage.

Vetri also syncs bundled skills on `vetri update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from your profile's `~/.vetri/skills/` tree, it is still shipped with Vetri; restore it with `vetri skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.
